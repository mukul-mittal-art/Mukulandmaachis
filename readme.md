# How did i make it?
* I made a rough sketch on paper on how i want it to look
* I imported all necessary files and pictures
* Then, i began with index.html (home page), made the navigation bar.
* From then, each page had different features, so on home page, i used z-index to overlap elements.
* On poetries page, i use display grid to make a grid to showcase my poetries.
* On artworks page, I inserted my instagram post with the help of embed.
* On design page, i insrted my instagram post and used a grid to show my posts in a grid.

# Problems i faced
* How to overlap elements? ( z-index)
* How to feature my poetries in a grid (display: grid)
* How to insert instagram posts and change their size (embed and using !important while changing size to overwrite)
* How to make my images lift up when cursor goes on them (hover effect)
These were some of the major problems i faced, among countless minor ones that increased this project's worktime ;-;
